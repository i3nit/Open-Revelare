# 去牛顿环（实验）

新增的本地 AI 分析、研究基线、mamba 训练和验证见 [AI 去牛顿环](newton-ai.md)。

编辑器的「去牛顿环（实验）」面板提供自动候选识别，以及可涂抹任意形状的区域笔和排除笔。源文件不被修改；修复作为可关闭、可调强度、可撤销的逐帧校正层保存。

这是实验性干涉纹抑制工具，**不能保证自动范围都是真实牛顿环，也不能保证全部去除**。特别是织物、砖墙、印刷网点、规则灯光、胶片齿孔等真实重复结构，可能与干涉纹共享频率。请检查范围和画面细节，必要时用手绘范围限制处理。

## 使用

1. **自动模式**：点击「自动识别并修复」。蓝色覆盖显示候选处理范围，关闭「显示牛顿环范围」查看修复后的画面。可用「排除区域」保留不应改变的位置。
2. **手绘模式**：用「涂抹区域」拖出受影响区域，形状由笔划的并集决定，不限圆、椭圆或规则环。用「排除区域」擦去不应修复的位置，再点击「修复手绘区域」。此按钮使用手绘范围，不再使用自动范围。
3. **强度**：0 等于不应用修复。优先从较低值开始；高值会同时削弱处于相同频带的真实细节。
4. **亮度纹修复**：默认较低，侧重色彩干涉。对灰度、近同相明暗纹可提高；提高后更需要检查纹理和对比度。
5. **检测灵敏度**：修改后再次点击分析按钮。强度和亮度修复比例可实时调整，不需要重跑检测。
6. **比较与恢复**：关闭「启用去牛顿环」查看原有处理结果；「清除牛顿环修复」删除本帧的校正层和笔划，也可以撤销。分析支持取消；切换图像、编辑参数或更换胶卷后，过期分析不会覆盖新状态。

手绘区域笔支持 `[ / ]` 调整半径。范围随当前裁剪、90° 旋转、拉直、翻转和镜头畸变映射到源坐标；预览、放大后的局部预览和导出复用同一源坐标校正场。

## 方法与泛化范围

- 在反转之前的源线性 RGB 中取对数，估计乘性干涉对应的加性扰动。正片、负片不需要使用不同的圆形模板。
- 使用 64 / 128 / 256 / 512 像素的重叠局部窗口和不同频带。小窗口跟随弯曲及局部方向变化，大窗口估计较宽的干涉纹。没有圆心、半径、椭圆率或同心环约束。
- 自动候选同时检查谱峰的局部突出程度、空间上是否重复明暗交替，并用对立色通道相位作为置信度辅助。相位差不是必要条件，灰度或近同相干涉也能进入候选。
- 在选定频带估计对数色度和亮度校正，保留未选频带，而不是整片涂抹、模糊或用邻近图块覆盖。校正场叠加窗羽化，手绘笔划另有边缘羽化。
- 手绘分析的频谱约束较宽松，适合自动漏检时尝试，但也更容易损伤真实细节。排除区和未选择的区域不应用校正。
- 固定精度的校正场在首次预览前量化，随后压缩保存；打开工程不会引入新的量化步骤。同一场用于预览和导出，导出时不重新识别。

目前是传统信号处理方法，没有宣称训练过通用牛顿环语义检测模型。合成曲线干涉纹的测试不能证明对所有真实扫描都有效；与画面结构相同的周期、非常宽的非周期色斑、超出分析分辨率的极细条纹、剪切饱和造成的信息缺失，仍可能无法正确分离或恢复。它也不是去摩尔纹、去尘和补全缺失内容的统一替代品。

局部频率分析和多尺度分析分别可参考 [Rojo & Harrington, 2006](https://arxiv.org/abs/astro-ph/0605609) 与 [Sun et al., 2018](https://arxiv.org/abs/1805.02996)。本实现没有复现论文中的完整方法，也未使用其训练权重或将其中的实验结果作为本功能的质量指标。

## 工程兼容性

包含牛顿环校正层、笔划或启用状态的工程使用 `.ncproj` v5，防止旧程序静默忽略修复。未使用该功能的工程保持原来的 v2/v3/v4 兼容规则。校正数据有尺寸、数值、压缩载荷和笔划数量上限。可继续调整原来的色彩、曝光和裁剪参数，不修改原片。

## 本次验证

新增测试覆盖直线、椭圆、扭曲、变频、灰度、鞍形和交叉干涉纹、真实色块阶跃的误选保护、范围外像素保持不变、排除笔、关闭与零强度、校正层保存后的逐像素一致性，以及区域渲染与整帧的一致性。工作流测试覆盖自动 / 手绘、裁剪旋转翻转后的坐标、撤销重做、保存、取消和源文件 SHA-256 不变。

```bash
dotnet test src/OpenRevelare.Tests -c Release --filter 'FullyQualifiedName~Newton'
```

用户指定的 `DSC01934.ARW` 至 `DSC01937.ARW` 已在现有 `scratch/test-roll/RAW/` 副本上测试。自动诊断输出位于 `scratch/newton-verification/`，每张 `*-comparison.jpg` 从左至右为：原结果、校正后、候选范围。`report.json` 记录候选覆盖、处理耗时和结果变化量；**候选覆盖不是识别准确率，变化量也不是修复质量**。真实样片没有无牛顿环的配对真值，不能据此报告客观去环百分比。

另有 `scratch/newton-manual-verification/` 的全源图手动选择压力测试，用于观察宽松频带在大范围应用时的损伤风险。这不是建议的范围，也不是用户实际绘制的牛顿环标注。实际使用应尽量缩小手绘区域。

可复跑的工具：

```bash
dotnet run --project benchmarks/OpenRevelare.NewtonVerification -c Release -- <输出目录> <工程.ncproj或-> <RAW文件...>
# 诊断用全图手绘压力测试：在末尾添加 --manual
```

本机的本地 SDK 启动方式与 [135 自动裁切说明](auto-crop-135.md) 相同。图像副本、诊断输出、校正场样本和 SDK 均留在 Git 忽略的 `scratch/` 下，不随代码提交。
